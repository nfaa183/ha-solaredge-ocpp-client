# SolarEdge OCPP Client for Home Assistant

Home Assistant app that keeps a **SolarEdge ONE EV charger** (KEBA KC-P30) visible in
the SolarEdge app while the charger is controlled locally by Home Assistant
(OCPP integration, evcc).

See [the app documentation](solaredge_ocpp_client/DOCS.md).

## Installation

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fnfaa183%2Fha-solaredge-ocpp-client)

Or: **Settings → Apps → App store → ⋮ → Repositories**, add
`https://github.com/nfaa183/ha-solaredge-ocpp-client`, then install **SolarEdge OCPP Client**.

Related: [solaredge-keba-local-ha](https://github.com/nfaa183/solaredge-keba-local-ha),
the local control setup this app complements.
